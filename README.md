 🎮 Rock Paper Scissors Game
 Challenge the computer in the classic Rock 🪨, Paper 📄, Scissors ✂️ battle! Built with HTML, CSS, and JavaScript, this game offers an interactive and engaging experience with real-time score tracking and instant game results.

---

🚀 Features

✨ Interactive and user-friendly interface
🎯 Real-time Player vs Computer gameplay
🔀 Randomized computer move generation
🏆 Instant win, lose, and draw notifications
📱 Responsive design for desktop and mobile devices

---

🛠️ Technologies Used

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript 

---

🎮 How to Play

1. Choose **🪨 Rock**, **📄 Paper**, or **✂️ Scissors**.
2. The computer makes a random choice.
3. The winner is determined by the classic rules:

| Choice      | Beats       |
| ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors |
| ✂️ Scissors | 📄 Paper    |
| 📄 Paper    | 🪨 Rock     |
